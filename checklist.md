# Incident Response Checklist

## Triage (first 10 minutes)
- [ ] Acknowledge the page in #incident-live
- [ ] Record start time and current severity in the channel topic
- [ ] Assign an incident commander and a communications lead

## Mitigation
- [ ] Identify the last known-good deploy
- [ ] Roll back or mitigate, then confirm the error rate has recovered
- [ ] Page the owning team if the blast radius is unclear

## Handover / wrap-up
- [ ] Add a timeline entry for every action taken
- [ ] Downgrade severity only after metrics hold for 30 minutes
- [ ] File the follow-up ticket and name the postmortem owner
